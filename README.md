# YouTube Podcast Player (Android)

An Android application designed to play podcasts using the YouTube backend. This app focuses on an audio-first experience, allowing users to discover, subscribe to, and stream their favorite podcasts directly from YouTube.

## Features

* **YouTube Backend Integration:** Uses YouTube as the primary source for podcast content. If required, integrates with the YouTube Music Podcast API to specifically search for and find podcasts.
* **Episode Management:** View a list of podcast episodes, whether hand-picked directly or aggregated from subscribed podcast channels.
* **Podcast Search:** Easily search for podcast channels and discover new content.
* **Audio-Only Extraction:** Pulls and plays only the audio track from a specified YouTube video/podcast episode to save data and optimize the listening experience.
* **Offline Caching:** Saves the audio locally during playback. The local cache is maintained until the episode is fully played.
* **Subscription Tracking:** Keeps track of all your subscribed podcast channels.
* **Episode State Tracking:** Within each subscribed podcast, episodes are tracked by state:
  * **New:** Freshly released episodes.
  * **Playable:** Episodes ready to be listened to.
  * **Already Played:** Episodes that have been fully consumed.
